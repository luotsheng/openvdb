# v1.1.0

## ⭐ 新增新能

- 支持`SQLite`数据库
- 支持`PostgreSQL`数据库
- 新增数据表格右键菜单，支持复制为 `INSERT` 和 `UPDATE` 语句
- 新增全局状态栏，显示当前正在执行的 `SQL` 语句
- 新增执行查询、更新等语句日志显示以及执行耗时
- 支持代码编辑器中选中表时添加`打开设计表`右键菜单
- 支持代码编辑器自动保存数据到文件
- 新增右键菜单弹出动画
- 新增已保存的查询脚本文件详细信息列表面板
- 支持数据表格复制为`JSON`格式

### 本次新增

- 主题系统：支持浅色 / 深色 / 跟随系统，并持久化到用户配置，弹窗统一皮肤
- 底部状态栏分区展示：连接上下文（连接名 / 库 / 模式）、数据库类型与版本、最近一次执行结果、后台任务进度、编辑器光标与选区
- SQL 编辑器上下文智能补全：按 `FROM` / `JOIN` 引用的表与别名过滤，`t0.` 只提示对应表字段；字段补全显示列注释
- SQL 编辑器表名交互：按住 `Cmd` / `Ctrl` 悬停显示蓝色下划线并展示表注释，点击跳转到设计表
- 补齐各模块右键菜单：
  - 连接：新建查询、刷新、复制连接名
  - 数据库 / 模式：新建查询、刷新、复制名称
  - 表：复制查询语句、清空表、删除表
  - 查询：复制查询名 / 路径、在文件夹中显示
  - 结果表格：提交修改、新增行、设置为 `NULL`、导出、删除选中行（危险操作置底）
  - 执行日志 / 表设计器：常用操作
- 表格搜索结果命中文本黄色高亮标记
- 多行文本单元格改为弹出编辑框编辑
- 连接密码使用 `AES-GCM` 加密存储（本地密钥）

## 👻 优化功能

- 优化高分辨率下图标模糊问题
- 优化了右键菜单样式，新增圆角边框、模糊等效果
- 优化树节点渲染逻辑，支持动态节点渲染
- 优化查询脚本保存以及节点联动功能
- 优化代码补全逻辑，使用异步加载，避免创建编辑器卡顿
- 优化节点加载逻辑，避免重复双击导致节点多次加载
- 优化数据表格奇数偶数行背景色以及表格选中样式
- 优化导航树节点选中样式以及选中背景色

### 本次优化

- 执行日志面板重构：语句块化、标签分色（`EXECUTE` / `QUERY` / `UPDATE`）、时间戳、左侧竖线、失败语句整块红色背景、顶部「清空 / 复制」按钮
- 右键菜单贴近 macOS 原生观感（浅色纯白底、深色 `#2c2c2e`、亚克力过渡）
- 编辑器滚动条改为圆角 + 主题蓝
- 表格选中行增加浅色底，便于定位当前行
- 顶部菜单栏不显示数据库图标（macOS 原生菜单栏图标会被放大）
- 主窗口保留原生装饰，移除统一的工具栏内边距调整
